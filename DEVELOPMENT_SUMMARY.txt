1. SOROBAN SMART CONTRACT (76+ commits)
================================================================================

The FinchippayContract is a production-grade Soroban WASM contract implementing:

Tips              One-shot token transfers with on-chain aggregate stats
Receipts          Immutable payment-receipt metadata, NFT receipt minting
Escrow            Time-locked token custody with claim/cancel, dispute resolution
Streaming         Continuous per-ledger token streams with claim/top-up/close
Multi-Sig         N-of-M threshold approvals with auto-execute at threshold
Batch Sends       Fan-out transfers to 50+ recipients in single transaction
Vesting           Cliff + linear vesting with revocation
Yield Escrow      AMM/DeFi pool integration scaffold (feature-gated)
Airdrops          Merkle-tree airdrop with claim verification
Batch Swaps       Multi-token swap with path validation, slippage protection
Emergency W/D     Time-delayed, multi-sig-gated token rescue
Admin Governance  N-of-M admin signer set with propose/approve actions

Security Properties:
- require_auth() on every mutating entrypoint (38+ call sites)
- Checked arithmetic: checked_add/checked_sub/checked_mul throughout
- Storage TTL: MIN_TTL_LEDGERS floor (535,680 ledgers), bump on read/write
- Emergency pause: separate pauser role, circuit breaker pattern
- Token transfer verification: require_transfer_succeeded() guards phantom deposits
- Bounded inputs: MAX_ESCROW_AMOUNT, MAX_STREAM_DEPOSIT, MAX_BATCH_SIZE, etc.
- Duplicate detection: self-transfers blocked, duplicate signers rejected
- On-chain invariants: assert_invariants() validates state consistency
- 11 libFuzzer targets covering all critical entrypoints
- 4 integration test files + property-based streaming tests
